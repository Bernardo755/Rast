El navegador no entrega IMEI, MAC ni número de serie. El ID de rastreo es un identificador único que se guarda en este navegador, y cada punto lo lleva junto con la batería y la red.

API de Geolocalización del navegador

Geolocalización por IP

Aproximada (ciudad). No pide permiso. Consulta ipapi.co.

Google Geolocation API (Wi‑Fi y antenas)

Necesita una API key propia. Se usa solo en tu navegador y no se guarda.

App nativa o híbrida (Capacitor)

Para seguimiento en segundo plano. Código de ejemplo:

npm i @capacitor/geolocation
import { Geolocation } from '@capacitor/geolocation';
const p = await Geolocation.getCurrentPosition({
  enableHighAccuracy: true });
console.log(p.coords.latitude, p.coords.longitude);
Geolocation.watchPosition({}, (pos) => { /* ... */ });

También: Cordova, React Native (react-native-geolocation-service) o Flutter (geolocator).

Rastreo con servidor

Tus puntos se difunden por BroadcastChannel: abre esta página en otra pestaña del mismo navegador para ver el receptor. Para un servidor real, conecta un WebSocket que envíe y reciba JSON {"lat":…,"lon":…}.

Hardware GPS (NMEA)

Pega sentencias NMEA de un módulo (ESP32, Arduino, SIM7000, Traccar…). Se leen GGA y RMC.

La ubicación se procesa en tu navegador. Los métodos 2, 3 y WebSocket requieren red hacia otros sitios y HTTPS.
